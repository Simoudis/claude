# voice: Jerry Rose

For `@jerryroseevents` and `@jerryrosehomeandgarden`. Every `ig-*` skill uses
this file instead of `voice.md` when the request names either account or
Jerry Rose. Built on 2026-10-19 from the `jerry-rose-brand` skill (baseline
September 7, 2026). That skill is the authority; if the two disagree, it wins,
and this file should be corrected. TODO items are unknown and must not be
guessed.

## How this file overrides the pack

The pack is built for growth accounts. Jerry Rose is a design house whose
copy communicates how the studio sees, designs and cares, not what it sells.

- **Line one is a concrete design detail tied to a principle,** not a hook
  formula. "The vessel sets the proportion." Never "stop scrolling", "nobody
  tells you", "here's why", or a question asked for engagement.
- **25 to 70 words** by default. `caption.py` length checks still apply; a
  short caption is the house style, not a fault.
- **No hashtags, emoji, sales language or tagline by default.** Skip the
  `/ig-hashtag` step unless the user asks for tags, and say so in the receipt.
- **No keyword CTA, no DM funnel, no invented scarcity.** When an ask helps,
  tie it to the actual service and season ("Fall container plantings are
  booking now" only if true and approved). Often there is no ask. A
  `caption.py` warning about a missing ask is intended.
- **Write as "we".** "I" only when the user explicitly asks for Jerry's or
  John's individual voice.
- **The account is named with each photo.** The user says
  `@jerryroseevents` or `@jerryrosehomeandgarden` per post. If a request does
  not say which, ask; never guess from the image.
- **Authorship:** a photo assigned to either account shows Jerry Rose Inc.
  work, so "we designed / we planted / we composed" is accurate. Client
  names, addresses and venues still need authorization.
- **Photo credit:** every caption ends with its own last line,
  `Photos: @simoudis`. All photographs are by John Simoudis.
- **Never describe an image that has not been inspected.** No species,
  venue, date, client or authorship inferred from filenames, mood boards or
  renderings. Image pairings are suggestions until someone looks.
- **Humanize with the brand lexicon.** The stock `slop.json` rewrites
  "curated" to "picked", which breaks Curated by Nature and The Year, Curated.
  Always run `humanize.py --lexicon <this folder>/jerry-rose.slop.json` (the
  stock list minus `curate`/`curated`). Regenerate it if `slop.json` changes.
- `/ig-viral`, `/ig-comment`, `/ig-dm` and `/ig-story` funnels assume growth
  tactics. Use them only if asked, and filter their output through this file.

## The Jerry Rose Point of View

The ongoing editorial series. Each post picks one pillar, connects one
concrete visual or project detail to one principle, and where helpful one
human consequence.

| Pillar | Subjects |
| --- | --- |
| How We See | Composition, color, proportion, scale, editing, surprise |
| How Nature Leads | Seasonality, botanical character, movement, gardens, materials |
| How People Live | Collections, homes, rituals, traditions, stories, entertaining |
| How Hospitality Feels | Arrival, anticipation, comfort, discretion, generosity, host confidence |

Working design question: "What belongs here?" Use it as a lens, not a
slogan, and never as a claim of ownership.

## What we sound like

- **Register:** a creative director's specificity and a good host's warmth.
  Confident, editorial, observant, intelligent, approachable. Detail
  communicates luxury; adjectives do not.
- **Moves:** active verbs, concrete nouns, short sentences, one idea per
  paragraph. Explain a choice: why this vessel, this color relationship, this
  scale, this placement, this seasonal material.
- **Words that help when they clarify:** proportion, gesture, composition,
  rhythm, texture, sculptural, collected, garden-rooted, seasonal.
- **Do not repeat as branding:** curated, intentional, quiet, belongs. Vary
  them.
- **Never:** exquisite, vintage splendor, layered immersive, grocery store
  flowers, elevate your experience, unforgettable magic, "where X meets Y",
  empty luxury superlatives.
- **Avoid:** repeated "not X, but Y". State the positive idea directly.
- **Never dismiss** other styles, budgets, designers or clients.
- **Emoji:** none by default.
